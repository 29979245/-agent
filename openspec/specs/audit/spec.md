## Purpose

为 AI 生成的化学题目提供安全与质量闸门：方程式级确定性四维校验 + 题目级四维 LLM 评审，双层合成审核状态并驱动教师审批 / 自动重生成工作流，确保配平准确率 100% 红线与题目质量达标后才可入库下发。

## Requirements

### Requirement: 方程式级四维安全审核
系统 SHALL 对化学方程式执行确定性四维安全校验：系数配平、反应条件、产物正确性、分子结构。系数配平 MUST 达到 100% 准确率（确定性算法，不依赖 LLM 配平）。

#### Scenario: 配平正确的方程式四维全过
- **WHEN** 输入方程式化学计量数已配平且反应条件、产物、分子结构均正确（如 CH4 + 2O2 -> CO2 + 2H2O）
- **THEN** 四个维度全部通过，方程式级结果判定为 passed

#### Scenario: 系数未配平的方程式被阻断
- **WHEN** 输入方程式的化学计量数不平衡（如 CH4 + O2 -> CO2 + H2O）
- **THEN** 系数配平维度判定失败，方程式级结果判定为 blocked

#### Scenario: 条件、产物或结构问题软标记为 warning
- **WHEN** 输入方程式配平正确但反应条件缺失、产物不稳定或分子结构格式异常
- **THEN** 对应维度判定失败（软标记），方程式级结果判定为 warning 而非 blocked（doc 26 §11.3：仅配平硬阻断）

### Requirement: 题目级四维评审
系统 SHALL 对 AI 生成的题目进行四维 LLM 评审：科学性、难度匹配、知识点覆盖、区分度，每维 0-100 分。综合分 MUST 按加权和计算：科学性×0.4 + 难度×0.25 + 知识点×0.2 + 区分度×0.15。

#### Scenario: 按权重计算综合分
- **WHEN** 题目完成四维评分（如科学性 90 / 难度 80 / 知识点 85 / 区分度 75）
- **THEN** 系统按 0.4/0.25/0.2/0.15 权重计算出综合分（该例为 84.25）

#### Scenario: 科学性单维低于 70 直接阻断
- **WHEN** 科学性评分 < 70（即使其他维度与综合分较高）
- **THEN** 题目级结果判定为 blocked

### Requirement: 双层合成与审核状态判定
系统 SHALL 合并方程式级与题目级两层结果生成最终审核状态。任一层 blocked -> 整体 blocked；任一层 warning -> 整体 warning；两层均 passed -> 整体 passed。题目级综合分映射：>=80 passed / 70-79 warning / <70 blocked；科学性单维 <70 直接 blocked。最终状态 MUST 写入题目的审核状态字段并持久化双层审核报告。

#### Scenario: 两层均通过判为 passed
- **WHEN** 方程式级 passed 且题目级综合分 >=80 且无单维低于 70
- **THEN** 最终审核状态为 passed，双层审核报告写入题目记录

#### Scenario: 任一层 blocked 判为 blocked
- **WHEN** 方程式级 blocked 或题目级综合分 <70（或科学性单维 <70）
- **THEN** 最终审核状态为 blocked，阻断题不可下发给学生

#### Scenario: 任一层 warning 判为 warning
- **WHEN** 两层均非 blocked 且任一层 warning（如题目级综合分 70-79）
- **THEN** 最终审核状态为 warning，题目可用但需人工复核

### Requirement: 审核状态机
系统 SHALL 依据最终审核状态驱动工作流：passed -> 教师 approve 后入库；warning -> 教师 approve 放行（带复核标记）或打回重生成；blocked -> 自动重生成（每次重新走两层审核）至多 3 次，3 次仍 blocked 则标记为"出题失败"（不自动替换，由教师决定处理）。

#### Scenario: passed 题教师批准后入库
- **WHEN** 审核状态为 passed 且教师执行 approve
- **THEN** 题目进入题库，审核状态更新为已入库

#### Scenario: warning 题教师放行带复核标记
- **WHEN** 审核状态为 warning 且教师执行 approve 放行
- **THEN** 题目进入题库并带复核标记

#### Scenario: warning 题教师打回重生成
- **WHEN** 审核状态为 warning 且教师执行打回重生成
- **THEN** 系统重新生成题目并再次执行两层审核

#### Scenario: blocked 题自动重生成至多 3 次
- **WHEN** 审核状态为 blocked
- **THEN** 系统自动重生成并重新审核，累计至多 3 次

#### Scenario: 3 次重生成仍失败标记出题失败
- **WHEN** 自动重生成 3 次后最终审核状态仍为 blocked
- **THEN** 题目标记为"出题失败"，不自动替换题库中已有题目

### Requirement: 审核 API 端点
系统 SHALL 提供审核工作流 API，且 MUST 仅限教师及以上权限访问：题目生成响应内嵌双层审核报告；支持对已存储题目重新审核；支持教师批准入库/放行；支持教师触发重生成。

#### Scenario: 生成响应内嵌双层审核报告
- **WHEN** 教师提交 AI 出题请求
- **THEN** 生成响应包含题目及方程式级四维 + 题目级四维 + 综合分 + 最终审核状态的完整双层报告

#### Scenario: 对已存储题目重新审核
- **WHEN** 教师对已存储的题目发起重新审核
- **THEN** 系统重新执行对应触发范围的审核并返回双层审核报告

#### Scenario: 教师批准题目
- **WHEN** 教师对审核状态为 passed 或 warning 的题目执行批准
- **THEN** 题目按状态机规则入库（warning 附带复核标记）

#### Scenario: 教师触发重生成
- **WHEN** 教师对 warning 或 blocked 的题目触发重生成
- **THEN** 系统生成新题目并重新执行两层审核

#### Scenario: 无权限用户访问被拒绝
- **WHEN** 非教师及以上权限的用户调用审核工作流 API
- **THEN** 请求被拒绝并返回未授权错误

### Requirement: 审核触发范围
系统 SHALL 按题目来源区分审核范围：AI 生成走两层审核（方程式级 + 题目级）；手动录入 / OCR 导入只过方程式级硬闸（题目级跳过）；配平工具只跑方程式级校验；学生对话与实验模拟不纳入本次审核范围。

#### Scenario: AI 生成走两层审核
- **WHEN** 题目由 AI 生成链路产出
- **THEN** 系统执行方程式级四维校验与题目级四维评审两层审核

#### Scenario: 手动录入与 OCR 导入只过方程式级
- **WHEN** 题目来自手动录入或 OCR 导入
- **THEN** 系统只执行方程式级四维校验，跳过题目级评审

#### Scenario: 配平工具只跑方程式级
- **WHEN** 用户调用配平工具校验方程式
- **THEN** 系统只执行方程式级四维校验，不触发题目级评审
